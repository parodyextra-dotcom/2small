# 2종소형면허 회원관리 시스템

## 프로젝트 개요
2종 소형면허 교육 회원을 관리하는 웹 애플리케이션입니다.

## 주요 기능

### ✅ 회원 관리 (index.html)
- 회원 등록/수정/삭제/검색/필터링
- 최신 등록순 정렬 표시
- **필드**: 이름, 나이, 성별, 전화번호, 등록일자, 검정일자, **지역**, **직업**, **등록이유**(소개/인터넷검색/유튜브/전단지/기타), 진행상태, 성격, 특이사항

### ✅ 단체 문자
- 조건별 회원 선택 (전체/교육전/교육중/시험대기/합격/불합격)
- 🎓 1년 이내 수강생 자동 선택
- 🎓 졸업생홍보 템플릿

### ✅ 통계 대시보드
- 일일/주별/월별/년별 기간 선택
- **신규회원은 등록일(reg_date) 기준**으로 카운트 (활동로그 기반 X)
- 활동 추이 바 차트 / 도넛 차트
- 일별 상세 통계 테이블

### ✅ 엑셀 + 그래프 리포트 다운로드
- **엑셀 (7시트)**:
  - 📊 종합 대시보드 (기간 요약, 요일별·등록이유별·지역별·직업별 분석)
  - 일별 요약 / 전화 발신 상세 / 문자 발송 상세
  - 신규 회원 상세 (등록일 기준)
  - 전체 회원 현황 (지역/직업/등록이유 포함)
  - 📈 분석 그래프 (텍스트 바 차트)
- **HTML 그래프 리포트** (자동 동시 다운로드):
  - Chart.js 기반 인터랙티브 차트 4종
  - 등록이유별/지역별/직업별 비율 바 차트
  - 인쇄/PDF 저장 지원

### ✅ 관리자 통계 리포트 (report.html) — **NEW**
- **다른 관리자가 읽기 전용으로 통계를 조회**할 수 있는 별도 페이지
- **2026년 4월 1일부터** 데이터 조회 가능
- 날짜 범위 선택 (오늘/어제/이번 주/이번 달/최근 7일/최근 30일/전체)
- 4개 탭 구성:
  - 📊 **종합 개요**: 일별 활동 바 차트, 활동 비율 도넛 차트, 요일별/상태별/등록이유별/지역별/직업별/성별 분석
  - 📋 **일별 상세**: 날짜별 전화/문자/신규회원 통계 테이블 (주말 하이라이트)
  - 👥 **신규 회원**: 기간 내 신규 등록된 회원 상세 목록
  - 🕒 **활동 로그**: 기간 내 전화/문자/등록 활동 타임라인
- 인쇄/PDF 저장 지원
- index.html 헤더에서 [리포트] 버튼으로 바로 이동

## 페이지 구조

| 경로 | 설명 |
|------|------|
| `index.html` | 메인 회원관리 시스템 (회원목록, 회원등록, 단체문자, 통계) |
| `report.html` | 관리자 통계 리포트 (읽기 전용, 2026-04-01부터 조회) |

### index.html 탭 구성

| 탭 | 설명 |
|-----|------|
| 회원목록 | 회원 리스트, 검색/필터 |
| 회원등록 | 회원 등록/수정 폼 |
| 단체문자 | 일괄 문자 발송 |
| 통계 | 통계 대시보드 + 일별 상세 + 엑셀 다운로드 |

### report.html 탭 구성

| 탭 | 설명 |
|-----|------|
| 종합 개요 | 차트 + 다차원 분석 (요일/상태/등록이유/지역/직업/성별) |
| 일별 상세 | 날짜별 활동 통계 테이블 |
| 신규 회원 | 기간 내 신규 등록 회원 상세 정보 |
| 활동 로그 | 전화/문자/등록 활동 타임라인 (최근 200건) |

## 데이터 저장

| 키 | 설명 |
|-----|------|
| `members_data` | 회원 목록 (LocalStorage) |
| `activity_logs` | 활동 로그 — 전화/문자/신규등록 (LocalStorage, 최대 500건) |

## 기술 스택
HTML5 / CSS3 / JavaScript / Chart.js / SheetJS / Font Awesome 6 / Noto Sans KR / LocalStorage

## 개발 메모
- `report.html`은 `index.html`과 동일한 LocalStorage 데이터를 **읽기 전용**으로 조회합니다.
- 데이터는 동일 도메인에서 공유되므로 별도 서버 없이 동작합니다.
- 최소 조회 가능 날짜: 2026-04-01
